Self-host

Run the API and workers locally or on your own infrastructure. Sibling checkouts of adapters and analyzer are required for the api package path dependencies.

On this page

  1. Prerequisites
  2. API
  3. Stockfish
  4. Web
  5. Environment notes

Prerequisites

  • Node.js 20+ (CI commonly uses 22)
  • pnpm 10+
  • PostgreSQL 16 (or compatible) for persistent analyses
  • Optional Redis for shared rate limits / queue

API

cd api
pnpm install
cp .env.example .env
# set DATABASE_URL, and API_KEY_PEPPER for key hashing
pnpm build
pnpm migrate
pnpm start

Health check: GET /v1/health should return JSON with status, service, and apiVersion.

Stockfish

cd analyzer
pnpm install
pnpm engine:download

Binary is not committed. License is GPL v3; keep NOTICE and source pointer. Optional: AXIOMCHESS_STOCKFISH_PATH.

Web

cd web
pnpm install
pnpm tokens:sync
# set NEXT_PUBLIC_API_BASE_URL to the API origin
pnpm dev

Environment notes

  • Never commit .env or real secrets. Use .env.example placeholders only.
  • ANALYSIS_RETENTION_DAYS defaults to 30.
  • REDIS_URL enables Redis-backed limiters when reachable.
  • URL ingest rejects non-allowlisted hosts (SSRF gate).

Also read Privacy and Auth and quotas.
