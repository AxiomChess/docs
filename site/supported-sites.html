Notes

  • Lichess: one request at a time from a worker; after HTTP 429 wait at least 60 seconds. Docs: https://lichess.org/api.
  • Chess.com: Published-Data API only. PubAPI has no single-game endpoint; fetch_game uses composite ids username/YYYY/MM/id from list_recent_games. Docs: Published-Data API.
  • Allowlisted web hosts for URL ingest: lichess.org, www.lichess.org, chess.com, www.chess.com.
  • Variants: standard only.
