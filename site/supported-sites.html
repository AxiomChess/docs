Supported sites

v1 ships two adapters. Capabilities are advertised by GET /v1/sites and the adapters package sites.manifest.json.

  2. Lichess

Manifest

Machine-readable list: adapters sites.manifest.json (version 1). HTTP: GET /v1/sites.

Site idAuthCapabilitiesVariants
lichessnoneparse_url, fetch_game, list_recent_gamesstandard
chesscomnoneparse_url, fetch_game, list_recent_gamesstandard

Lichess

  • Base: https://lichess.org public API only.
  • Docs: https://lichess.org/api
  • On HTTP 429 wait at least 60 seconds before retry.
  • Fixtures under adapters/fixtures/lichess/; offline tests in CI.

Chess.com

  • Base: https://api.chess.com/pub/ only.
  • Archives and monthly games / PGN paths as documented by the Published-Data API.
  • No single-game PubAPI endpoint; fetchGame uses composite ids username/YYYY/MM/id from listRecentGames.
  • Fixtures under adapters/fixtures/chesscom/.

Shared error codes

not_found, private_or_unavailable, rate_limited, unsupported_variant, upstream_error.

Extension rules

Add a site only with documented public access, allowlisted hosts, fixtures, and SSRF-safe URL parsing. If no legal public route exists, do not add an adapter. See Ethics.
