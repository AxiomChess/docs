Free and open-source chess fair-play analysis for finished games. Engine-backed reports with suspicion bands, uncertainty, and methodology notes -- never a raw accusation. This wiki is the long-form reference for operators, integrators, and players.

Product wiki

AxiomChess analyzes finished public games or user-supplied PGN. It is an educational analysis aid, not a federation tribunal and not live cheat detection.

What AxiomChess is

AxiomChess offers a public HTTP API, a web app, and Stockfish-backed feature extraction that produces a calibrated suspicion score with an uncertainty interval. Every result carries methodology notes and false-positive guidance.

Supported ingest in v1:

  • Public game URL (Lichess or Chess.com, allowlisted hosts only)
  • PGN paste (no site call)
  • Username recent public games (paged list; optional analyze)

Bands are only low, elevated, high, and inconclusive. The product never emits a definitive guilt label.

Public-API-only. Lichess official public API and Chess.com Published-Data API only. No private games, no login scraping, no rate-limit evasion.

Analysis pipeline (summary)

  1. Ingest -- URL, PGN, or username via adapters; SSRF allowlist for URLs.
  2. Normalize -- canonical PGN + metadata (NormalizedGame).
  3. Engine eval -- Stockfish UCI, MultiPV 3, depth policy engine-v1.
  4. Features -- top-1/top-3 match, CPL, timing if clocks, opening-book boundary.
  5. Calibrate -- score S in [0,1], half-width, ordinal band.
  6. Output -- AnalysisResultV1 JSON + human report.
