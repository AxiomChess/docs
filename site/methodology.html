Methodology and calibration

Policy ids: engine policy engine-v1 and calibration policy calibration-v1. This page freezes the documented formula used by the analyzer package. Do not change cut points to make fixtures pass; cut a new policy id instead.

Engine policy engine-v1

  • Engine: official Stockfish via UCI (pinned release documented in analyzer NOTICE).
  • MultiPV = 3.
  • Depth = 18 for standard time controls; Depth = 16 for bullet when that policy branch runs.
  • Threads and Hash are worker-sized and recorded in result metadata.

Opening book: snapshot opening-book-v1 from lichess-org/chess-openings (CC0). Book plies are excluded from match statistics; the novelty ply is reported.

Score formula

All arithmetic is IEEE-754 float64. Clamp x to [0, 1].

  1. cplSignal = 1 - clamp(cpl.average / CPL_SOFT_CAP, 0, 1)
  2. matchSignal = 0.55 * top1Rate + 0.20 * top3Rate + 0.25 * cplSignal
  3. If timing present: timingBoost = TIMING_BOOST_MAX * clamp(fastHighMatchStreakMax / TIMING_STREAK_CAP, 0, 1); else 0.
  4. S = clamp(matchSignal + timingBoost, 0, 1)

PRIOR_TOP1 / PRIOR_TOP3 are design anchors; the v1 blend uses raw rates directly so the score stays monotone in match rates.

Uncertainty

  1. If usablePlies <= 0: halfWidth = 0.5, interval [0, 1].
  2. Else baseHw = UNCERTAINTY_K / sqrt(usablePlies); halfWidth = min(0.5, baseHw + (timing ? 0 : MISSING_CLOCK_EXTRA_HW)).
  3. Interval: low = max(0, S - halfWidth), high = min(1, S + halfWidth).

Mandatory notes

Every result includes methodology identity (policy ids), false-positive warning, and sample-size caveats (short games, missing clocks, book length).

False-positive guidance

  • Strong players can match engine lines without assistance.
  • Prepared openings inflate early match rates; book exclusion mitigates but does not eliminate theory effects.
  • Missing clocks remove timing evidence and widen uncertainty.
  • Short games often land in inconclusive by design.

Authoritative freeze text also lives in analyzer/docs/calibration-v1.md.
