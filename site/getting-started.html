Getting started

Use the web app for interactive analysis, or call the HTTP API from your own tooling. Both paths share the same ethics constraints and band vocabulary.

On this page

  1. Web app
  2. API quick path

  5. Next reading

Web app

  1. Open the AxiomChess web deployment (local pnpm dev in repo web, or your hosted URL).
  2. Go to /analyze.
  3. Choose public game URL, PGN paste, or username lookup for lichess / chesscom.
  4. Wait for the job to complete, then open /report/{id}.

Set NEXT_PUBLIC_API_BASE_URL to a running API. Private or unavailable games fail with a clear error; the UI does not encourage private-game access.

API quick path

GET /v1/health
# expects JSON with status, service, apiVersion

POST /v1/analyze/pgn
Content-Type: application/json
{ "pgn": "<canonical or near-canonical PGN>" }

GET /v1/analyses/{id}

Anonymous default quota: 10 analyses / day / IP, burst 2 / minute. Details: Auth and quotas.

Machine-readable contract: GET /v1/openapi.json.

Accepted inputs

InputBehavior
Game URLHost must be allowlisted; adapter fetches public game; fails closed if private
PGN pasteValidated and normalized; no upstream site call
UsernameLists recent public finished games; optional analyze queue

Standard chess only in v1. Unsupported variants return a clear error.

How to read a report

  • Band -- ordinal label from calibrated score and uncertainty gates.
  • Score S -- continuous value in [0, 1] under policy calibration-v1.
  • Uncertainty -- half-width; if too wide or sample too small, band is inconclusive.
  • Features -- match rates, CPL, timing when clocks exist, book boundary.
  • Notes -- methodology and false-positive warnings always present.

Full formula: Methodology. Band cut points: Scoring bands.
