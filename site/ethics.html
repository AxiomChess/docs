Ethics and public-API-only policy

AxiomChess analyzes finished games using engine-backed features and a calibrated suspicion score with uncertainty. It is an educational analysis aid, not a tribunal. Reports never output a definitive "cheater" label.

Hard rules

  1. Use only documented public endpoints and user-supplied or public PGNs.
  2. Lichess: official public API at https://lichess.org only. Respect one-request-at-a-time guidance; after HTTP 429 wait at least one minute before retry (per Lichess API tips).
  3. Chess.com: Published-Data API base https://api.chess.com/pub/ only. Public read-only data; no private chat, conditional moves, or authenticated-only surfaces.
  4. Add another site only when a legal public route or standard public PGN export is documented. If none exists, do not add an adapter.
  5. No account takeover, captcha bypass, private-game access, HTML scraping behind login, or rate-limit evasion.
  6. Reports must present uncertainty, methodology notes, confidence bands, and false-positive guidance.
  7. Prefer a player's own games or clearly public games. UI and docs must state limits and false-positive risk.

Non-goals

  • Live cheat detection during ongoing games
  • Access to private games or login-gated data
  • Definitive guilt labels without uncertainty
  • Guaranteeing legal findings for federations or platforms
