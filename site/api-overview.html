API reference

Public HTTP API for fair-play analysis. Paths match PROJECT_SPEC. Machine-readable OpenAPI is served at GET /v1/openapi.json. Education-first: responses never emit a definitive guilt label.

Auth and quotas

Defaults from the api package docs/quotas.md (aligned with PROJECT_SPEC):

Analysis quota defaults
SubjectDaily analysesBurst
Anonymous (per client IP)10 / day2 / minute
API key200 / day20 / minute
  • Send an API key with Authorization: Bearer <key> or X-API-Key: <key>.
  • Keys are hashed at rest (SHA-256 over pepper + raw key). Raw keys are never stored.
  • Quota cost: each analysis create or completed-cache hit on POST /v1/analyze/* consumes 1 unit. Username listing without analyze: true does not consume analysis quota.
  • Rate-limit headers when quota is consumed: X-RateLimit-Limit, X-RateLimit-Remaining, X-RateLimit-Reset; Retry-After on 429.
  • Public self-serve key minting is out of scope for v1.

Expanded detail: Auth and quotas.

Response cache

Identical completed analyses are reused by content hash of normalized PGN plus engine policy id (engine-v1). Cache hit responses include X-Cache: HIT; misses include X-Cache: MISS.

Errors

Stable JSON error shape: code, message, optional details, requestId. Adapter and upstream failures map to shared codes without leaking secrets. Common adapter codes include not_found, private_or_unavailable, rate_limited, unsupported_variant, upstream_error.

Supported sites

GET /v1/sites returns the adapters sites.manifest.json contract. Human-readable table: Supported sites.

Ethics constraints

  • Official public site APIs only; no private-game access or login scraping. This is the public-API-only policy.
  • URL ingest is SSRF-safe: only allowlisted hosts for supported sites.
  • Reports present uncertainty and methodology; never a definitive guilt label.
  • Full policy: Ethics.
