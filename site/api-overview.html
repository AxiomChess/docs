API reference

Public HTTP API for fair-play analysis. Paths match PROJECT_SPEC.md. Machine-readable OpenAPI is served at GET /v1/openapi.json from the api service. Education-first: responses never emit a definitive "cheater" label.

Base path

/v1

Routes

Versioned REST surface
Method Path Purpose
GET /v1/health Liveness / readiness summary
POST /v1/analyze/url Analyze by public game URL (SSRF allowlist)
POST /v1/analyze/pgn Analyze by PGN body
POST /v1/analyze/username List recent public games for username and site (paged); optional analyze queue
GET /v1/analyses/{id} Get analysis job or result (404 if expired)
DELETE /v1/analyses/{id} Hard-delete analysis by id (privacy erasure)
GET /v1/sites List supported sites and capabilities (adapters manifest)
GET /v1/openapi.json OpenAPI 3.1 document for this API version

Auth and quotas

Defaults from the api package docs/quotas.md (aligned with PROJECT_SPEC.md):

Analysis quota defaults
Subject Daily analyses Burst
Anonymous (per client IP) 10 / day 2 / minute
API key 200 / day 20 / minute
  • Send an API key with Authorization: Bearer <key> or X-API-Key: <key>.
  • Keys are hashed at rest (SHA-256 over pepper + raw key). Raw keys are never stored.
  • Quota cost: each analysis create or completed-cache hit on POST /v1/analyze/* consumes 1 unit. Username listing without analyze: true does not consume analysis quota.
  • Rate-limit headers when quota is consumed: X-RateLimit-Limit, X-RateLimit-Remaining, X-RateLimit-Reset; Retry-After on 429.
  • Public self-serve key minting is out of scope for v1; operators insert key hashes via operator tooling.

Response cache

Identical completed analyses are reused by content hash of normalized PGN plus engine policy id (engine-v1). Cache hit responses include X-Cache: HIT; misses include X-Cache: MISS.

Errors

Stable JSON error shape: code, message, optional details, requestId. Adapter and upstream failures map to shared codes without leaking secrets.

Supported sites

GET /v1/sites returns the adapters sites.manifest.json contract. Human-readable table: Supported sites.

Ethics constraints

  • Official public site APIs only; no private-game access or login scraping.
  • URL ingest is SSRF-safe: only allowlisted hosts for supported sites.
  • Reports present uncertainty and methodology; never a definitive "cheater" label.
  • Full policy: Ethics and public-API-only policy.
