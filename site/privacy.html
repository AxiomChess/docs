Privacy notice

Short notice for operators and users of the AxiomChess API and related services. AxiomChess does not sell personal data. This page summarizes storage, retention, and erasure; it is not legal advice.

What is stored

  • Analysis inputs (submitted PGN or public game references) and analysis results needed to serve GET /v1/analyses/{id}.
  • Optional API key metadata: key hashes only (SHA-256 with a server pepper). Raw keys are never stored.
  • Structured request logs with a request id. Info-level logs use a PGN content hash, not full PGN bodies.

Public games and user-supplied PGN

Processing covers publicly available finished games fetched through documented site APIs (see the ethics page) and PGN supplied by the caller. Private games are not in scope. Prefer a player's own games or clearly public games.

Retention and erasure

  • Default analysis retention is 30 days (ANALYSIS_RETENTION_DAYS), configurable by the operator.
  • Expired analyses are treated as unavailable on read (GET /v1/analyses/{id} returns 404). Operators should run expiry purge to hard-delete expired rows.
  • Hard erasure by id: DELETE /v1/analyses/{id} (HTTP 204 on success).

Reports

Reports present calibrated suspicion bands with uncertainty and methodology notes. They never emit a definitive "cheater" label. False-positive risk remains, especially for short games or missing clocks.
