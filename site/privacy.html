Privacy notice

AxiomChess stores only what is needed to run analysis jobs and honor retention and erasure. The product does not sell personal data.

On this page

  1. What is stored
  2. Retention
  3. Erasure
  4. API keys
  5. Logs
  6. Processing basis (planning)

What is stored

  • Analysis inputs and results (including normalized PGN while retained).
  • Optional API key metadata (hashed secrets only).
  • Request logs with request identifiers; IP retention is limited by operator configuration.

Do not invent additional personal data categories in integrations without documenting them here.

Retention

Default retention for analyses is 30 days (ANALYSIS_RETENTION_DAYS). Operators may configure a different TTL; document the deployed value in your ops runbook. Expired analyses are not returned by GET /v1/analyses/{id} (404).

Erasure

Clients and operators can hard-delete an analysis with:

DELETE /v1/analyses/{id}

Successful erasure responds with HTTP 204. After deletion, GET returns 404.

API keys

Keys are hashed at rest with SHA-256 over pepper:rawKey. Raw keys are never stored. Invalid or revoked keys return 401 with code: invalid_api_key. Public self-serve key minting is out of scope for v1.

Logs

Structured logs use requestId. Info-level logs use PGN content hashes rather than raw PGN bodies by default. Do not log secrets.

Processing basis (planning)

Legal basis for public game analysis is processing of publicly available game data and user-supplied PGN, with minimization and erasure of stored analyses by id. This notice is not legal advice; operators should review their jurisdiction.

Summary: AxiomChess does not sell personal data. Retention defaults to 30 days. Erasure is available via DELETE /v1/analyses/{id}.
